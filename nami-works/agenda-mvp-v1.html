Notes vs. current state

Section A is one paragraph appended below the existing "Ver todas as edições" link on /noticias/[edicao].astro — no layout change, no new section, just one more block after .ctaRow. The marker phrase ("mexeu com o seu trabalho") deliberately echoes the site's own lexicon for what the news line already promises ("o que muda no seu trabalho"), so the jump from reading an edition to this line reads as continuation, not a new pitch.

/agenda reuses BaseLayout.astro + marketing.css + the .display/.mk system exactly as shipped this session on the rest of the site — no new visual language. The widget shell has a fixed min-height across all four states specifically so the page doesn't jump when Cal.com's script finishes loading (a real CLS risk with third-party embeds — Core Web Vitals budget still applies even with no ad spend behind this page).
