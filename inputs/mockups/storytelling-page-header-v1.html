What changes vs. the current (broken) state

  • Compact icon back-button (32×32, chevron-left) replaces the full-text "Back" button. Matches Shopify's native order page header pattern. The label ("Back to Storytelling", "Back to Settings", "Back to Brand") becomes accessibility-only — visible on hover tooltip + announced by screen readers.
  • Drops the <Link> wrapping + variant="tertiary" override on the <s-button slot="back-action">. Those two together were forcing the s-button to render as a regular text button at full label width instead of letting Polaris auto-render the slot as the compact native back affordance.
  • Heading + secondary actions + primary action all inline on one row — no more vertical drift caused by a wide back element pushing content down.
  • Sub-page meta (date, source, etc.) — if any — sits indented below the heading, lined up under the title text, not under the back button.
