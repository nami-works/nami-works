Local Delivery — stat blocks parity (mockup v1)

The Auto-assign accuracy block and the Total savings block live next to each other in the LD sidebar but were built in different sessions with different primitives. They show information at different weights, place the period in different positions, and use different CTA styles. This mockup proposes a unified shape both blocks honor.

The five deltas

  • Title — Total savings uses a custom <div class="label"> at 12px/500 subdued. Auto-assign uses real <s-section heading> at 14px/600. Fix: both use <s-section heading>.
  • Period placement — Auto-assign has it at the bottom as a single subdued line. Total savings has it mixed into the delta inline. Fix: both put period at the bottom as a single subdued line.
  • Visual position — Auto-assign bar is at the top, above the stat. Total savings sparkline is at the bottom, below the stat. Fix: both put the visual indicator at the top.
  • CTA — Auto-assign has none. Total savings has a custom text-style <Link class="seeMore">. Fix: <s-button variant="secondary"> right-aligned at the bottom (Total savings only — Auto-assign has nothing to link to yet).
  • "New" badge — Custom green pill rendered as NEW all-caps. Fix: real <s-badge tone="success"> with title-case "New" next to the heading.

Anatomy — the shape both blocks honor

┌─────────────────────────────┐
│ Heading        [optional]   │ ← s-section heading + optional s-badge
│                             │
│ ▰▰▰▰▰░░░░░░░░░░░░░░░░░░░░░  │ ← Visual at top (bar / sparkline)
│                             │
│ 37%   descriptor text       │ ← Primary stat + secondary descriptor
│                             │
│ Period · count or unit      │ ← Period footer, subdued, single line
│                             │
│                  [See more] │ ← Right-aligned secondary button
└─────────────────────────────┘
  • Heading — <s-section heading={...}> · optional <s-badge tone="success">NEW</s-badge> rendered next to heading text
  • Visual — Progress bar (Auto-assign) or sparkline (Total savings), full width
  • Primary stat — Large numeric value + secondary descriptor on the same baseline, e.g. "37%   112 of 303 orders accurately assigned" or "−R$ 146   vs warehouse"
  • Period footer — Subdued single line, e.g. "Last 30 days · 40 optimizations" or "Last 90 days · 0% MoM"
  • CTA — Optional <s-button variant="secondary">See more</s-button> right-aligned

Trade-offs to call out

  • Total savings gets taller. Splitting the inline "vs warehouse · last 90 days · — 0% MoM" into descriptor + footer adds one extra line (~14px). The CTA button is also slightly taller than the previous text link. Acceptable IMO — readability + parity win.
  • Sparkline moves to the top. Currently the eye lands on the absolute number first. After the change the eye lands on the trend first. Matches Auto-assign (which leads with the bar). If you want value-first ordering, we keep the current order but still apply the heading + footer fixes.
  • "NEW" badge stays. No defined retirement date — leaving it in place but rendered as a real <s-badge tone="success">. Easy to remove later.
