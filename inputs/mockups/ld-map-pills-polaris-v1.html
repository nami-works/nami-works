Local Delivery — map pills, Polaris parity (mockup v1)

The current map pills don't show their per-route tone pairing on dark map tiles — the 78% white-mix bg used everywhere washes out against the dark slate background, even though it reads cleanly on the white side-panel route cards. This mockup compares the current state vs two ways to fix it.

What's changing

  • Typography — 14px/700 sans-serif → 12px/600 Polaris stack (matches the side-panel .routeBadge).
  • Border — 1.5px solid #111 removed → replaced with box-shadow: 0 1px 2px rgba(0,0,0,.25) for elevation against any map style.
  • Radius — 999px (full pill) → 10px (matches Polaris s-badge family and the side-panel card).
  • Tone pairing — apply BOTH bg AND text from deriveBadgeColors (today only bg is applied; text stays default #1f2933).
  • Unassigned markers — fall through to Polaris-neutral pairing (#e4e5e7 / #303030) instead of pure white.
  • Icons — hand-rolled SVG → Polaris <s-icon>; hourglass (due-today) → bolt (lightning).
  • Selected state — holographic gradient + edit-mode ring kept as-is (no Polaris equivalent and it's load-bearing UX).

Decision needed (from chat)

  • Option A — Deeper mix on map only. Map markers get a more saturated bg (rgb(140,198,183) for green Route 02). Side panel stays at 78% mix (rgb(199,227,220)). Map readable on dark or light tiles. Slight family-of-shades difference between map and side panel.
  • Option B — Same mix + force light map. Map and side panel use identical pastel. Requires default map style = light. Loses the dark map aesthetic. Pixel-identical parity.
