v3 — what changed from v2

  • Company-first, not Omnify-first. Hero headline drops the "behind Omnify" framing for the user's chosen tagline. Sub-copy orbits FMCG + omnichannel + Shopify, mentions no product by name.
  • Products plural. Two cards: Omnify with the live admin screenshot (featured, 2-col on desktop) + Storefront as a compact "Coming soon" teaser with a merchandising-themed visual (price-tag tiles) and a "Join the waitlist" button.
  • Mobile-first CSS rewrite. Base styles target mobile (stacked hero, single-column products, 36px headline, 16px body). Desktop overrides live in @media (min-width: 760px). Touch targets now all ≥44px.
  • Omnify link target swapped: no longer points at the auth shell omnify.cpg-labs.io (reviewer would hit a login redirect). Now points at omnify.cpg-labs.io/screencast, the existing public video-demo route.
  • Primary hero CTA changed from external link to internal scroll: "See our products" → #products. Keeps the reviewer on the page and answers the plural-product directive immediately.
  • About section reshaped around the company. Title: "Worldwide omnichannel solutions, built in Brazil." Body drops all tech-stack jargon (AWS, session tokens, API version lists) for a "solid and secure" trust signal at the human level. Replaces "small" with "independent" per user directive.
  • Nav simplification on mobile: only brand + "See Omnify" CTA visible below 760px. Products/About/Contact links hide on mobile, reappear on desktop. Keeps the mobile nav clean.
  • Waitlist mailto on Storefront card submits to contact@cpg-labs.io with a pre-filled subject. Zero-backend for the mockup. Swap for a real inline form at production ship time if desired.
