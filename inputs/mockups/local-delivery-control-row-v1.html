Local Delivery — control-row reorganization

Replaces the on-map polyline-edit toolbar overlay AND the existing footer-right row with a single state-driven control panel below the map. Each button is visible only when in-context. Secondary actions (today: Map style) live in the ⋯ More menu. Collapsed map block renders icons only; expanded (fullscreen) renders icons + names.
