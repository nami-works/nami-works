Phase-2 decisions locked (2026-05-10)

  • Placement: right sidebar of LD page, below Auto-assign accuracy. Same width as the existing sidebar blocks (280px in expanded layout). Inherits the mobile order: -1 rule from the LD page so it renders first on small viewports.
  • Content: headline savings number + MoM delta + 90-day sparkline + See-more button. ~80px tall card. No per-city breakdown — that's what the full analytics panel does.
  • Empty state: provocation teaser ("You could be saving ~R$ X / month") mirroring state #3 of the analytics panel. Falls back to conservative empty (state #4 here) if Intelipost speculative-quote feasibility check fails.

Phase-3 follow-ups (carry into spec)

  • Loader integration. The existing LD page loader is the slow one (14-17s baseline, perf work pending). Add a separate fetcher for the savings number so it doesn't extend the main loader's wall-clock. Loads in parallel via useFetcher() after the main page paints. Skeleton shows while it fetches.
  • Sparkline data source. 12 weekly buckets of LdAnalyticsDaily rolled up by week. Lightweight Prisma group-by. Cache for 1h to avoid re-running on every page hit.
  • Total savings = which framing? Match the LdAnalyticsConfig.headlineFraming setting. Default net_cost_delta (post-phase-4 pivot) — show as positive savings number when delta is negative (LD costs less than warehouse). Picker stays only in the full panel.
  • MoM trend calc. Compare last 30 days total to previous 30 days, expressed as %. Color the arrow per CLAUDE.md status colors: green for positive trend, red for negative, neutral for ±2%.
  • Disabled-state hide. Loader returns { analyticsAside: { kind: "hidden" } } when opt-in is off, so the component returns null. No empty placeholder.
  • "New" pill. Show for first 14 days after the merchant first enables analytics, then remove. Persist in LdAnalyticsConfig.asideFirstSeenAt (new column).
  • Stale rule. >36h since last successful rollup → state #5 (warning footnote). >72h → drop back to state #4 (conservative empty, treat data as unreliable).
