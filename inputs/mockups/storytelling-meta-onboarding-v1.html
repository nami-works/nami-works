Meta IG/FB onboarding — mockup v1 (in-block tabbed)

Iterated to use the same in-block tabbed flow as the Monday.com source row — for parity across all configurable integrations. The Meta row's accordion body holds 3 phase tabs (A: What we sample · B: Generate token · C: Paste & connect) plus an Edit view for already-configured merchants. No modal. Brand mark uses the existing MetaLogo component (the single Meta corporate wordmark) instead of re-rendering the IG + FB glyphs from the row list.

What this iteration changes (vs. earlier modal version)

  • Modal removed — the 3 screens become 3 tabs inside the accordion body. Same content, no overlay, parity with Monday.com.
  • Brand mark uses the existing MetaLogo component (the Meta wordmark already shipped in app/components/brand-icons.tsx). The duplicated inline IG + FB glyphs are gone.
  • Tab structure mirrors Monday's: phaseTabs row with active / done / pending states. ✓-prefix on done tabs.
  • Trust strip moves from Screen 1 into Tab A's body. Still calms fear before the merchant invests time on Meta's side.
  • Edit view: condensed single-section under the accordion body — same shape as Monday's edit view.

Open Meta Business Suite in a new tab, then follow these 3 steps. We'll wait here while you do.

1
In business.facebook.com → Settings → Users → System Users.
Don't have a System User yet? Click Add, name it "Omnify tone access", role Admin.
2
Click Generate New Token. Select your IG/FB asset, choose permissions: pages_read_engagement, instagram_basic, pages_show_list.
Token expiration: select Never for the long-lived flow.
3
Copy the token shown on the screen. Then come back here.

Decisions baked in

  • ✅ In-block tabbed flow matching the Monday.com mockup. 3 tabs: A (What we sample) · B (Generate token) · C (Paste & connect). Same component, same CSS classes.
  • ✅ Brand mark via MetaLogo from the existing brand-icons component — single Meta wordmark, no duplicated IG/FB glyphs inside the source body.
  • ✅ Trust strip migrates into Tab A — calms fear before the merchant invests time on Meta's side.
  • ✅ Edit view is condensed (no tabs) — already-onboarded merchants get a summary chip row + form fields + actions. Mirrors Monday's edit view shape.
  • ✅ Back button preserves state across tabs.
  • ✅ Faux Meta screenshot in Tab B step 3 kept as a confidence-builder for "what the merchant should be looking for."

Deferred

  • Real screenshots of Meta Business Suite (need to capture from a live account). v1 ships with ASCII placeholders; replace before launch.
  • Per-account scoping (currently 1 IG + 1 FB max). Multi-account sampling deferred to v2.
  • Auto-refresh-before-expiry — the token has a 60-day lifecycle; a notification 7 days before expiry is post-v1.
  • Real OAuth (no paste) — would need the app to register as a Meta App and run the full handshake. Deferred per the earlier "paste credentials" decision.
