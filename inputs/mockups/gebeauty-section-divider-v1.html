divisores de seção — opções

Elementos HTML/CSS puros (sem JS) para dar respiro entre seções. Tokens da marca GE. Cada opção aparece entre duas "seções" de exemplo.

A

espaço puro

Só respiro vertical, sem traço. Máxima leveza.
seção anterior
próxima seção
<div class="gebd-a"></div> .gebd-a{ height:88px } /* 64px no mobile */
B

filete fino

Linha discreta de ponta a ponta. Neutra e limpa.
seção anterior
próxima seção
<div class="gebd-b"></div> .gebd-b{ height:1px; background:#e7e3dd; margin:60px auto }
C

filete esmaecido

Linha que some nas pontas. Elegante e suave.
seção anterior
próxima seção
<div class="gebd-c"></div> .gebd-c{ height:1px; margin:60px auto; background:linear-gradient(90deg,transparent,#d9d4cc 16%,#d9d4cc 84%,transparent) }
D

barra curta vermelha

recomendadoAcento curto na cor da marca. Limpo + claramente GE.
seção anterior
próxima seção
<div class="gebd-d"></div> .gebd-d{ width:56px; height:4px; border-radius:2px; background:#DF3630; margin:60px auto }
E

filete com ponto

Linha completa com um ponto vermelho no centro.
seção anterior
próxima seção
<div class="gebd-e"></div> .gebd-e{ position:relative; height:1px; background:#e7e3dd; margin:60px auto } .gebd-e::after{ content:""; position:absolute; left:50%; top:50%; width:9px; height:9px; border-radius:50%; background:#DF3630; transform:translate(-50%,-50%) }
F

marca central (losango)

Dois filetes curtos com um losango vermelho ao centro. Mais decorativo.

próxima seção
