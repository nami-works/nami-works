Retail sales — chart refactor mockup

Proposed Shopify-native style for the Revenue by location and AOV drilldown charts. Flat two-tone bars, Y-axis with gridlines, per-location dashed goal marker, heavy metadata moved out of the chart body.

Changes vs current chart

  • Y-axis + gridlines added. Removes need for labels on every bar.
  • Flat fills. No gradients, no inset shadows, no dark navy.
  • Current = one bar with two tones — solid Shopify blue for MTD, pastel blue for projection stacked on top. No in-bar text labels.
  • PY = flat pastel-gray bar.
  • Goal = short dashed tick above each group at the goal level, red, with the goal value labeled compactly (e.g. "R$84k"). Replaces the floating red gradient bar.
  • Date context lives in the subtitle, not on every legend item — legend collapses to 3 entries (Current + projection, Prior year, Goal).
  • Per-location metrics as a mini-table under the bars — row labels pinned left (vs Goal, YoY), values aligned under each column. Chart stays clean; numbers stay glanceable.
  • Values live in tooltip on hover (mocked below on RioSul) for the absolute R$ figures.

Open questions for you

  • Goal display per location vs chart-wide. Mock uses a short dashed segment per location at that store's goal level. Alternative: skip the marker in the chart and keep goal info only in the breakdown table.
  • Tooltip vs persistent labels. Mock hides values; user hovers (or taps on mobile) to see exact figures. If we still want persistent numbers, we can keep a single label above the taller bar per group.
  • MTD / projection as one stacked bar vs two separate. Mock stacks them in a single column. Alternative: keep as a single solid bar (projected total) and skip the MTD split — matches Shopify purely but loses the "how far along are we" signal.
  • Achievement ranking tier thresholds. Mock uses ≥80% green / 60–79% yellow / <60% red. If the current page uses different thresholds, call them out and I'll align.
