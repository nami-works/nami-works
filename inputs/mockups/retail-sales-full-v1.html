Retail sales — full responsive redesign · mockup v1

Full page mockup of the Retail sales Dashboard tab, designed to fix the broken mobile layout (7-column breakdown table collapsed to a 2-column grid, producing stacked cells). Covers desktop + mobile end-to-end: overview strip, period bar, KPI scoreboard, drilldown chart, volume/quality row, breakdown table. The mobile version shows two alternatives for the breakdown table so you can pick the one that reads best. The Manage-goals modal is out of scope — already redesigned in v1.

Mobile breakages addressed

  • Breakdown table (primary issue). Current mobile CSS sets grid-template-columns: repeat(2, minmax(0, 1fr)) on a 7-cell row, producing stacked single-column chaos (headers on their own lines, values detached from their columns). Two fixes proposed below — pick one.
  • KPI cards on mobile. Desktop: 3 per row. Mobile: stack 1 per row (current) — they hold enough content (title, primary value, delta, projection, 1–2 lines) that 2-per-row would truncate. Kept stacked, tightened padding.
  • Drilldown chart. Already has overflow-x: auto. Tightened to y-axis 36px (from 44px), bars 15px (from 28px), intra-group gap 3px (from 6px), goal marker 40px (from 74px). Applied in the e4fff19 commit just now. Kept in mockup so mobile view is complete.
  • Overview strip. On mobile, heading wraps, period friendly drops to its own line, Manage goals button goes full-width below. This is an enhancement over the current flex-wrap behaviour which leaves the button floating oddly.
  • Period + Compare-with filter bar. Stacks 1-per-row at ≤768px (current behaviour, kept).

Design decisions baked in (desktop + mobile)

  • Achievement pill in table cells — color-coded (green ≥ 80%, yellow 60–79%, red < 60%) to match the Achievement ranking chart tiers. Adds color redundancy so achievement reads at a glance without the progress bar.
  • Consolidated "Revenue breakdown by location" copy unchanged; column set unchanged on desktop.
  • Option A (scroll) keeps the desktop table structure intact — zero cognitive overhead for desktop users who also visit on mobile. Shopify convention permits overflow-x: auto on tables.
  • Option B (cards) reshapes each row into a Shopify-admin-native card with a clear primary metric, secondary grid, and YoY footer. Better tap targets, easier scanning, but breaks from the desktop mental model.
  • All mobile bars + intra-group gaps ship the 768px treatment already committed (15px bars, 3px gap, 40px goal marker).
