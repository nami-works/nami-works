What this v1 (UX polish) adds vs. shipped page

  • ✅ Status indicator — chip-style pills replaced with right-aligned ● Status dot+text. Eliminates the variable-width pill alignment bug.
  • ✅ Accordion rows — clicking a row (or its chevron) expands the credentials form inline directly under the row header. Solves the "config card disconnected from row" pain point. Single-expand-at-a-time keeps page jumps bounded.
  • ✅ Merged Instagram + Facebook into one row. They share one credential set in the backend (BrandIntegrationConfig.integrationType=meta) — splitting them as 2 rows misled the merchant into thinking they were independent.
  • ✅ Merged manual upload + URL into one Manual references row. Same intent (add reference content), two intake methods, both rendered inside the expanded body.
  • ✅ Real brand glyphs — Shopify shopping bag (green), Instagram gradient camera, Facebook blue f, Monday three-bar mark, Polaris-style document for files, link icon for URLs. All inline SVG, 16-20px to match Polaris s-icon scale.
  • ✅ Manual references list moved INTO the expanded body — uploaded files only show when the Manual references row is expanded. Keeps the source list compact.

Decisions deferred / out of scope

  • Pending review + Past batches sections — kept as-is from shipped v1. No visual changes proposed in this iteration.
  • Status when Meta/Monday partially fail — e.g. IG token works but FB ID rejected. v1 assumes any error fails the whole row to "Error" state. A more granular "1 of 2 connected" indicator could come in a v2.
  • Drag-and-drop file upload — current dropzone takes click-to-choose only. True drag-drop is a follow-up.
  • Production code changes — strictly mockup-only this round per Lucas's instruction; backend wiring already shipped on rev 18+.
