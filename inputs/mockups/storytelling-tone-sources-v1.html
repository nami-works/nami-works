Storytelling tone sources — mockup v1

New sub-route at /app/brand-settings/tone-sources. Tab inside Brand settings. Pulls tone signal from Shopify blogs, Meta IG/FB, Monday.com, and merchant-supplied references (brandbooks via PDF/DOCX/TXT/MD upload OR pasted URLs); runs Claude inference; presents hypotheses for the merchant to accept or reject before they influence generation. Same human-in-the-loop pattern as the existing Storytelling Learnings page.

What this mockup decides

  • Page anatomy — three sections: Sources connection, Pending hypotheses (current batch), Recent batches (history).
  • Validation pattern — per-hypothesis Accept/Reject buttons, plus batch-level Accept all / Reject all. Mirrors /app/storytelling/learnings.
  • Source connection states — connected · disconnected · not configured. Per-source error banner stays inside the source row, doesn't blow up the page.
  • Manual + scheduled — "Refresh tone now" primary action; weekly cron handles steady state.
