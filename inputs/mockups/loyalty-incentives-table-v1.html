"Incentivos emitidos" route — mockup v1

Polaris-style admin table at app/routes/app.loyalty.incentives.tsx (planned, not yet scaffolded). Reads from IssuedIncentive Prisma table. Cross-campaign view covering loyalty A/B test enrollments + apology credits + future incentives. Single source of truth for "who has what, in what state."

Design decisions baked into this mockup

  • Row click = external drill to Shopify admin customer page (opens in new tab). Subtle ↗ indicator appears on customer name when row is hovered. Shopify admin owns the per-customer view (rendered by the customer-detail UI extension block from Phase 1.8).
  • Default filter = ACTIVE only. Page loads showing only currently-actionable incentives. User toggles status filter to see REVOKED / EXPIRED / REDEEMED. Active filter chips render below the bar showing what's applied.
  • Campaign label = hardcoded map in route file. Raw fiscal-hold-extrema-2026-05 renders as "Pedido de desculpas - Atraso CD Extrema". Loyalty-test arms render as "Teste de fidelidade - Arm A/B/C". Maintained manually; refactor to a Prisma `Campaign` table only when there are 5+ active campaigns.
  • Per-row kebab (⋮) = hover-revealed only. Appears on row hover or keyboard focus. MVP action: "Abrir cliente no Shopify ↗" (same as row click — redundant but explicit). Sets up Phase 4 expansion (Revogar / Estender validade / Reenviar notificação).
  • External-label filter pattern per CLAUDE.md Form Inputs convention. .filterControl + .filterLabel. Mobile: filters stack 1-per-row at ≤768px.
  • Pack wide rows per CLAUDE.md rule: Export CSV sits on the same row as the filters (right-aligned), not on its own row.
  • No emoji per CLAUDE.md hard rule. Kind icons are inline SVG (wallet for STORE_CREDIT, ticket-tag for DISCOUNT_CODE). Status uses colored Polaris-style badges with dots, no emoji.
  • Sort default: most recent first (by issuedAt desc). Customer / Amount / Issued / Expires columns are sortable; Campaign / Arm / Kind / Status are filter-only.
  • Expiry warning: yellow + bold when ≤7d remaining. Struck-through subdued when status=EXPIRED.
  • Pagination: 50 rows/page. Expected volume ~12k loyalty-test enrollments + 117 fiscal-hold + future. Cursor-based via Prisma; "Showing X-Y of N" footer.
  • Mobile (≤768px): filter bar stacks 1-per-row, table gets overflow-x: auto. Polaris IndexTable handles narrow-screen reflow natively in production; this mockup approximates with horizontal scroll.
