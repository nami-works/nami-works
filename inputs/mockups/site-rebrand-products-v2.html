Spec for production translation

  • Logo size: 96×96 desktop, 68×68 mobile, with a drop-shadow so it reads as floating, not pasted.
  • Logo position — Omnify: top-left of the card, offset top: -28px; left: -24px (desktop) — corner of the card pokes through the bottom-right of the logo.
  • Logo position — Storefront: anchored to the start of the text column (logo over the visual-text column boundary), offset top: -28px; left: 220px on desktop. Mobile reverts to corner placement since the card stacks.
  • Header reflow: name + badge stack vertically. Heading block carries left-padding equal to (logo width − left offset + ~12px gap) on desktop's Omnify card so text starts past the floating logo.
  • Card overflow: the products section's container needs overflow: visible (not hidden) so logos can extend past the card edge. The current featured card has a ::before glow with overflow: hidden on the card — we'll keep the glow but move overflow to visible on .productCard and clip the glow with a contained ::before sized within the padding, OR drop the glow on these two cards (it competes with the new logo glow anyway).
  • Badge styling: drop text-transform: uppercase and letter-spacing: 0.05em. Bump font-size from 10px → 11px so lowercase doesn't read as cramped.
  • Stack gap: increased from 24/32px → 56px so floating logos don't collide with the card above.
