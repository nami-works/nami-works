Storytelling brief — Track D mockup v1

Replaces the JSON-textarea editor at /app/storytelling/brief with a real campaign-builder UI. Themes are expandable; merchant fills in title, SEO phrase, summary, products, and keyword sets per theme. Reads existing brand context from BrandAssets + accepted BrandToneHypothesis traits (Phase 6) and surfaces them inline so the merchant knows what voice the AI will use before generating.

Decisions baked into v1

  • Accordion list, not tabs. Each theme is a collapsible card. Expanded by default for the first theme on a fresh brief; subsequent themes auto-collapse so the merchant scans before drilling in.
  • Chip-style keyword inputs. Type → enter creates a chip. Backspace removes the last chip. Mirrors Polaris-style tag inputs used elsewhere in the app.
  • Inline product picker per theme. Search + multi-select from this shop's products. Selected products render as green chips above the picker. Reuses the existing product loader from the route — same products fetched once, shared across all theme pickers.
  • Context band at top. Reminds the merchant which tone profile / brand assets will guide generation. One-click to /app/brand-settings/tone-sources if they want to refresh.
  • JSON escape hatch. Power users keep a "View as JSON" toggle — same data, raw editing. Useful for debugging, or for pasting briefs from another tool. Switches the form into a textarea while preserving state.
  • Validation happens on Generate — empty-title themes get a red border + inline error.
