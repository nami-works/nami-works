Footprint expansion — mockup v1

Full-page redesign of app/routes/app.footprint-expansion.tsx to align with the newly established color + card + chart conventions (CLAUDE.md → UI Patterns → Drilldown Charts, Tooltips, Aside Card Blocks, UI Tokens, Form Inputs). The current page leans on a teal/pink palette and gradient-filled bars that predate the Shopify-native chart refactor shipped on Retail Sales (2026-04-15). Goal of this mockup: validate the visual language before touching React. Desktop variant first, mobile variant at the bottom.

Audit — convention gaps in current production code

  • Off-brand chart palette. vbarBar, vbarStackOnline, vbarStackStore, vbarPileLabel, donut strokes, and gapRevenueBar all use teal #5ecece, pink #d4a8d4, and purple #b09fda — these predate the Shopify blue / pastel-blue / light-gray convention and don't appear anywhere in the UI Tokens table.
  • Gradient fills on bars. vbarBar uses linear-gradient(180deg, #5ecece, #b09fda, #d4a8d4); stacked bars and holographic sync bar also use gradients. CLAUDE.md Drilldown Charts: "Bars — flat fills only. No gradients, no inset shadows."
  • Holographic sync strip. syncProgressBarFill animates a teal→purple→pink gradient. Out of family with every other progress indicator in the app; replace with a flat Shopify-blue determinate bar.
  • Overview strip background. overviewStrip uses a pink→blue linear-gradient background. No other section in the app has a non-white background; replace with standard --card.
  • Active-card highlight uses teal. overviewBoxActive outlines in #5ecece with a pink→blue gradient background. Convention (KPI Drilldown Interaction): Shopify-blue border + subtle shadow, no background fill.
  • No chart frame on drill-down bars. vbarChart is a bare flex row with value labels floating above bars. Missing: 44px y-axis column, 5 gridlines, zero line, x-axis separator. Every Retail Sales drill-down uses the standard frame.
  • Values rendered above bars. Drilldown Charts convention historically said "No labels above bars." Refined on 2026-04-17: that rule applies only to multi-series comparison bars (PY / projection / goal). Single-KPI charts — which is what the Row-1 footprint drilldown is — keep the value label above each bar; the tooltip then enriches with the other two KPIs. Current code puts labels above bars but pairs with no tooltip at all.
  • No tooltip on drill-downs. No hover/focus tooltip exists. Convention: dark tooltip (#1f1f1f) with variance-first rows, absolute values, on-dark green/red.
  • Filter pattern inconsistent with rest of app. overviewPeriodSelect is a bare <select> with no external label; monthly-avg toggle floats with its own internal text. Retail Sales + Local Delivery use .filterControl + .filterLabel with labelAccessibilityVisibility="exclusive".
  • Filter row not packed. Sync link ("Sync", overviewSyncLink) sits on its own row below the period select even though there is plenty of horizontal space. CLAUDE.md: "Pack wide rows before starting new ones."
  • Cities ranking is gone from the UI. cityRankings is loaded but only wired into a per-city modal; there is no visible ranking list. Shopify-native convention: horizontal sorted list with Shopify-blue track fill, tiered variant when used for achievement.
  • Donut chart uses teal + pink + blur-shadow labels. Labels are inside the ring with white text + text-shadow for contrast, and a hover swap flips percentage ↔ order count. Convention: flat fills (Shopify blue + pastel), label sits below the ring (not inside), hover surfaces the tooltip not a label swap.
  • Gap cities table has decorative pastel bars. gapRevenueBar uses a teal→pink gradient. Tables convention: no zebra, subtle row borders, no decorative fill — bars can be Shopify blue at low opacity if a visual weight hint is needed.
  • Heatmap options exposed via <s-link>. CLAUDE.md: "never use <s-link> (its shadow DOM forces blue text that CSS cannot override)". Should be a plain <button> with the underline style.
  • "Sync" action is an <span> role="button">. Acts like a link but is a span with role button. Should be a real <s-button variant="plain"> or a proper Polaris link.
  • Overview section spacing drift. Row-labels overviewRowLabel use margin: 16px 0 8px on top + marginTop: 8px override for the first — irregular against the gap: 16px convention inside <s-stack gap="base">.
  • Sort arrow adhesion. renderSortArrow renders <span className={styles.sortArrow}>▼</span> without the non-breaking-space glue — when a column header is narrow (e.g. "Customers") the arrow can wrap to its own line. Convention (Tables): {"\u00A0"} between label and arrow.

Changes applied in this mockup

  • All chart fills switched to convention palette — Shopify blue #005bd3 for current, pastel #b3d1ff for projection, light gray #d9e3ef for prior year. Stacked bars and donuts use the same pair.
  • KPI cards rebuilt to standard frame — white background, light-gray border, Shopify-blue outline + 1px shadow on active. No background color on active, no teal, no gradient.
  • Drilldown chart uses the standard frame — 44px y-axis with 5 ticks, horizontal gridlines, flat blue bars, no value labels above bars. Values live in the tooltip, which now shows all three KPIs per city (Revenue · Customers · Orders) so the user can read the full picture without toggling cards.
  • Filter bar rebuilt with the external-label pattern — Period + Monthly-avg + Sync in a single wrapping row, right-aligned with the overview title on desktop, stacking full-width on mobile.
  • Sync strip restyled — white card, flat Shopify-blue progress bar when % is known. The holographic teal→purple→pink gradient is retained only on the indeterminate variant (when progress can't be computed) as a visual signature that the app is importing. Strip carries its own margin-bottom: 16px so it doesn't crash into the overview card below.
  • Cities ranking moved into the project-loaded view — does NOT render on the main overview. When a project is loaded the page enters the split layout (map + aside) and the ranking renders as an aside card underneath Expansion Projects, feeding from cityRankings which is already loaded but currently unused in the main UI.
  • Gap cities table — standard no-zebra frame, centered headers, row hover #f6f6f7, revenue bar at rgba(0,91,211,0.12) instead of pastel gradient.
  • Donut drilldown flattened — light-gray track + Shopify-blue fill, percentage in the center, label below. Hover surfaces a standard dark tooltip with both percentage and order count.
  • Mobile variant — filter bar stacks vertically, KPI cards stack one-per-row, map loses expand/collapse control.
