Affiliates · Auto-sync codes from Shopify + Attribution Queue UI revamp

Two paired changes: (A) coupon codes auto-sync from one or more registered Shopify code-discount nodes every hour, replacing the BixGrow CSV as the source of truth for which codes exist; (B) the Attribution Queue tab gains a single, honest freshness chip and a new Settings sub-tab for managing affiliate programs.

Changes vs current state

  • New Settings sub-tab on the Affiliates page — register one or more Shopify code-discount nodes as "affiliate programs" with a search-and-pick modal (no GID copy-paste).
  • Single freshness chip in the tab strip's right slot, sourced from AttributionQueueSnapshot.fetchedAt (the cron-driven timestamp). Shows ✓ Updated 14m ago when fresh, ⚠ Updated 3h ago when the cron has actually been stuck (>2h).
  • Force Full Resync + Update database move into a ⋯ More overflow menu — they're maintenance ops, not daily controls. Removing them from the primary action zone keeps the queue's center of gravity on the queue itself.
  • "Last sync: 4/20/2026, 7PM" badge is gone — that timestamp tracked the last manual full resync, not the cron. Confusing because the cron has been running fine.
  • "Affiliate data is N days old" warning is gone — replaced by the chip's own warning state, which only fires when the cron is genuinely stuck.
  • "Previous sync had issues: Unknown sync error" is gone — that error never auto-cleared after a subsequent successful sync. Sync errors now only surface as a precise message tied to the most recent run, and clear the moment the next cron succeeds.
  • "141 orders carry coupons not in the affiliate list — re-import the affiliate CSV" is gone — replaced by the inline ⓘ N codes need a profile → Open onboarding queue link. The fix is no longer to re-import a CSV; it's to onboard the affiliate (full editor in a follow-up; this deploy ships only the count + link).
  • BixGrow CSV upload still works — but its role is now "affiliate metadata only" (commission %, name, email, tier). Shopify's discount registry is the source of truth for which codes exist.
