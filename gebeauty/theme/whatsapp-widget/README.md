# GE Beauty — WhatsApp floating widget (theme snapshot)

Point-in-time record of the hand-built WhatsApp buy widget that lives **inline in the GE Beauty Shopify theme layout**. The theme is not checked into this repo, so these files are a reference snapshot, not the source of truth. The live store is authoritative.

- **Snapshot date:** 2026-07-04

- **Creds/API:** `SHOPIFY_ADMIN_ACCESS_TOKEN` in `gebeauty/.env`, Admin Asset API `2026-01`, Python `C:/Python314/python.exe`.

## Files
- `theme.liquid.widget.html` — the widget block as it appears in `layout/theme.liquid` (default layout; all normal pages + product pages).
- `theme.ctx.liquid.widget.html` — the same block in `layout/theme.ctx.liquid` (the geo/context-variant layout auto-generated by the **"Context by Relevant Bits"** app).

## What it is
A self-contained vanilla-JS widget (NOT the Hexagon SDK, NOT an app embed), delimited by `<!-- Hexagon WhatsApp Widget -->` and `<script id="hexagon-ge-whatsapp-widget">`. Three UI pieces:
- **Badge** `#hxWaBadge` — pill "compre pelo whats", white bg / 0.75px red border / red text (#DF3630), right-aligned to the button, single line. Visibility: hidden until the shopper scrolls past `badgeAppearVh` × viewport (1.0 = one full screen / second fold); then fades in (0.6s), shows 6s, fades out. One-shot per page (`badgeShownOnce`). Scroll-gated so it never overlaps the top cookies banner.
- **FAB** `#hxWaBtn` — round green WhatsApp button, bottom-right.
- **Panel** `#hxWaWidget` — header "compre pelo whatsapp", rows "com nosso assistente inteligente" (→ `wa.me/551142103680`, coupon `NO_SEU_TEMPO_40`) and "com uma de nossas lojas" (→ `linklist.bio/gebeauty_insta`), SAC link (`wa.me/5511945630346`), "Feito por Hexagon" footer.

## Tunable knobs
- `SHOW_BADGE` — kill switch for the badge (FAB/panel stay).
- `badgeAppearVh = 1.0` — badge appears after scrolling this many viewport heights (1.0 = one screen, 2.0 = two).
- Show duration — the `},6000)` in the scroll-trigger inside `updateBadgeOpacity` (ms visible before fade-out); fade duration is the badge's `transition:opacity .6s`.
- `BADGE_VIEW_LIMIT = 2` — habituation: badge shows on this many page views before going quiet.
- Reduced (quiet-mode) button size — `.hx-wa-btn.hx-wa-min` = 42px (75% of the 56px original), icons 22/15px, pulse + glow rings disabled.

## Quiet mode (suppression)
On a "not buying via WhatsApp" signal the badge is removed AND the FAB shrinks to half size (`hx-wa-min`, anchored bottom-right). Signals:
- on `/cart` or `/checkout`, or the cart drawer opens (add-to-cart) — session (`sessionStorage hx_badge_off`);
- opens the panel then closes it without tapping a row — session;
- badge shown on `BADGE_VIEW_LIMIT` page views with no interaction — `localStorage hx_badge_views`, resets on any engagement.

Tapping the FAB (opening the panel) counts as engagement: restores full size + resets the counter. There is a dormant 7-day explicit-dismiss path (`localStorage hx_badge_dismiss_until` + `dismissBadge()`), left in code but with no UI — the × control was removed 2026-07-04.

## Product-page specifics
- A `{% if template contains 'product' %}` block injects `<style id="hx-wa-pdp-lift">` that raises the FAB/badge/panel ~100px so they clear the pinned add-to-cart bar (its base value is my estimate — tune the `bottom:*px !important` values if it floats too high/low).
- While the cart drawer is open, the FAB and panel `z-index` drop to `1` so they sit **below** the drawer; restored when it closes.

## Editing SOP (both layouts, every time)
1. `GET /themes.json?fields=id,name,role` → confirm the `main` theme id.
2. Apply the identical change to **BOTH** `layout/theme.liquid` and `layout/theme.ctx.liquid` (they drift otherwise; ctx can be regenerated by the Context app and overwrite manual edits — a durable fix would move this into a shared snippet or app embed).
3. For JS changes, extract the `<script id="hexagon-ge-whatsapp-widget">…</script>` body and run `node --check` before PUT.
4. Edits are LIVE immediately; product-page HTML is CDN-cached, so hard-refresh (Ctrl+Shift+R) to verify.
