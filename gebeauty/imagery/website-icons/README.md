# GE Beauty website icons — canonical library

Normalized from `ICONS FINAIS.ai` (Drive `GB/IMGs`) via the /iconographer engine.
Each icon ships as a pair: `icon-<name>.svg` (`#DF3630` baked, the live `<img>` drop-in) +
`icon-<name>.currentcolor.svg` (themeable master). Standard: filled-outline, `viewBox 0 0 51 51`.
Scores are the auto-QA conformance score (`scripts/iconkit.py`). Extraction keeps the source's
unused label-glyph defs (hidden by the viewBox crop); harmless, can be stripped in a later pass.
