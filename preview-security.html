Security at CPG Labs

We keep your data always safe. Here is how we do it.

Encryption at Rest

All data stored in our databases is encrypted using AES-256 encryption via AWS RDS.

Encryption in Transit

All connections use TLS 1.2 or higher. API endpoints enforce HTTPS exclusively.

Access Controls

Role-based access control, principle of least privilege. Production requires MFA.

Infrastructure

AWS ECS Fargate with VPC isolation in us-east-1. Ephemeral containers rebuilt on each deploy.

Data Handling

We do not sell, rent, or trade your data. Google API data is used solely to power platform features.

Vulnerability Disclosure

Report security concerns to security@cpg-labs.io. We acknowledge reports within 48 hours.

Omnify is compliant with the Google API Services User Data Policy.
